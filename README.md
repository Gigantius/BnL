# BnL (Buy n List)

Вебзастосунок для колекціонерів монет України, що забезпечує облік особистої колекції,
каталогізацію монет, розміщення лотів та проведення угод між користувачами.
Назва розшифровується як Buy n List - «купуй і виставляй»: користувачі купують монети в інших колекціонерів і виставляють власні лоти.

Основа застосунку - готовий каталог обігових і пам’ятних монет України за всі роки.
Орієнтовні ціни автоматично оновлюються з відкритого каталогу [ua-coins.info](https://www.ua-coins.info/ua/catalog/all/all),
тому користувач бачить вартість своєї колекції без ручних підрахунків.

# Проблема

Колекціонери ведуть облік монет у таблицях або нотатках і вручну перевіряють ціни на кількох сайтах.
Купівля й продаж відбуваються в Telegram-чатах і групах соцмереж, де оголошення губляться,
не мають єдиної структури та не перевіряються, що підвищує ризик шахрайства.

# Мета

Створити вебзастосунок, у якому колекціонер в одному місці знаходить монету в каталозі,
веде облік колекції з автоматичною оцінкою вартості, продає дублікати й купує відсутні монети в інших користувачів.

# Цільова аудиторія

- Колекціонери-початківці, які хочуть знати, які монети існують і скільки вони коштують.
- Досвідчені колекціонери, які ведуть облік великої колекції та шукають монети для її доповнення.
- Продавці дублікатів, яким важливо показати реальний стан монети на фото.

# Ролі користувачів

| Роль | Можливості |
| --- | --- |
| Гість | Переглядає каталог, ціни та активні оголошення; реєструється й входить |
| Користувач | Веде колекцію, створює оголошення, купує монети, надсилає скарги, керує профілем |
| Модератор | Розглядає скарги, видаляє оголошення із зазначенням порушеного пункту правил |
| Адміністратор | Керує користувачами й ролями, каталогом і оновленням цін |

# Основні функції

- Каталог монет із пошуком і фільтрами (рік, номінал, метал, тип).
- Сторінка монети з характеристиками, фото та орієнтовною ціною.
- Особиста колекція з автоматичним розрахунком вартості.
- Оголошення про продаж із власними фото, що публікуються автоматично.
- Замовлення на купівлю зі статусами «Нове», «Підтверджене», «Відхилене», «Завершене».
- Скарги на оголошення та журнал рішень модератора.
- Керування користувачами й ролями.
- Щоденне автоматичне оновлення цін з ua-coins.info.
